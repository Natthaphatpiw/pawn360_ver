   ↓
[พนักงาน] กดยืนยัน + พิมพ์ข้อความ
   ↓
[Shop System]
   - บันทึก status = confirmed
   - ส่ง webhook → https://pawn360.vercel.app/api/webhooks/shop-notification
   ↓
[Customer System]
   - รับ webhook พร้อม QR code URL
   - ส่ง LINE Flex Message Card พร้อม QR code
   ↓
[ลูกค้า] สแกน QR → ชำระเงิน → อัพโหลดสลิป
   ↓
[Customer System]
   - ดาวน์โหลดรูปจาก LINE
   - POST → /api/notifications/payment-proof
   ↓
[Shop System]
   - อัพโหลดสลิปไป S3
   - ส่ง webhook แจ้งว่าได้รับสลิป (optional)

   ↓

🔐 Environment Variables ที่ต้องเพิ่ม:
ระบบร้านค้า (.env):
CUSTOMER_SYSTEM_URL=https://pawn360.vercel.app
WEBHOOK_SECRET=pawn360-webhook-secret
ระบบลูกค้า (.env.local):
SHOP_SYSTEM_URL=https://pawn360-ver.vercel.app
WEBHOOK_SECRET=pawn360-webhook-secret
LINE_CHANNEL_ACCESS_TOKEN=your_token
LINE_CHANNEL_SECRET=your_secret
🎯 ข้อดีของระบบนี้:
ไม่มี timeout: API ตอบกลับทันที ไม่รอ user action
Scalable: รองรับ concurrent requests ได้มาก
Reliable: Webhook retry 3 ครั้งด้วย exponential backoff
Secure: มี webhook signature verification
Decoupled: ทั้ง 2 ระบบทำงานอิสระกัน
LINE Integration: ส่ง Flex Message Card สวยงาม
